KeepMyMacAwake · Windows 开发预览 0.3.0

这是一份未签名、未在 Windows 真机验收的开发体验包，供本地开发和验收。
首个验收目标：Windows 11 x64。不能据此宣布所有机型均可用。

使用
1. 将整个 ZIP 解压到固定目录，保留所有文件。
2. 双击 KeepMyMacAwake.Windows.exe；无需自行安装 .NET。
3. 首次启动阅读说明。接通电源、保持开盖，再选择日常或夜间。
4. 设定时间，点击“开始保活”。关闭窗口会留在系统托盘。
5. 单击托盘杯子图标可重新打开；右键可停止或退出。

当前功能
接电开盖防闲置休眠、计时/无限时、加15分钟、显示器自动熄屏/常亮、
夜间画面遮罩、断网停止、偏好保存、可选登录启动。
柔光时托盘与控制窗口仍可操作；在控制窗口按 Esc 可停止。
网络表示系统路径，不保证 AI 服务可达；联网后不自动重新保活。

边界
合盖与电池保活尚未开放。应用热保护不可用，UI不会假装有热数据。
此包不会安装后台服务，不会修改合盖设置，不需要管理员权限。
保活不保证 AI 完成任务，不会阻止手动睡眠、重启、网络故障或等待输入。
锁屏和长时间运行仍需要本地验收，不改变锁屏策略。
请在通风桌面上使用；不能检测电脑是否在包内。

Windows 安全提示
此包没有 Authenticode 签名。Windows或企业策略可能阻止运行；
不要通过关闭系统防护、绕过管理策略或以管理员身份运行来解决。
签名与分发信誉需在正式交付前完成验收。

升级与移除
升级前先停止、关闭登录启动、从托盘退出，然后替换完整解压目录。
移除前同样关闭登录启动并退出，再删除解压目录。
偏好位于当前用户 LocalAppData/KeepMyMacAwake/windows，不包含运行会话。
