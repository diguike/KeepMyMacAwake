# 产品范围

## 已确定的定位

KeepMyMacAwake 是给普通用户使用的 macOS 菜单栏 App。安装后通过顶部菜单栏图标控制，无需输入命令。支持通风桌面上的长任务，例如 AI 编程、下载、构建、渲染和远程访问。

名称与目录已确定；具体图标、视觉设计和最终交互尚未确定。

## MVP

| 能力 | 用户看到的行为 |
| --- | --- |
| 一键保持运行 | 主开关开启后明确显示当前模式与剩余时间 |
| 定时结束 | 30 分钟、1 小时、2 小时、自定义；暂定默认 1 小时 |
| 合盖继续运行 | 首次启用引导授权；真正就绪后才显示可合盖 |
| 立即停止 | 撤销本应用保活，恢复本应用改动的设置 |
| 供电保护 | 暂定默认仅接电；允许用户显式选择电池模式 |
| 电量保护 | 暂定电池低于 20% 停止，阈值可设置 |
| 热状态保护 | 热压力持续严重或达到临界时停止；具体阈值待验证 |
| 异常恢复 | App 退出或崩溃后，由独立 helper 结束本应用保活 |
| 开机启动 | 只启动 App，不默认恢复上一次保活 |
| 状态解释 | 展示停止原因、授权问题、网络连接状态 |

这些默认值是设计提议，尚无测试数据支撑其最终取值。

## 菜单栏面板草案

```text
KeepMyMacAwake
合盖继续运行

保持运行                         [开关]
持续时间                      [1 小时 ▾]
合盖后也保持运行                     ✓
仅在接通电源时运行                   ✓

当前：未开启
网络：已连接

设置…                         退出
```

活动状态主文案示例：“保持运行中 · 剩余 58 分钟”。停止文案需要说明原因，例如：“已停止：已断开电源”。授权失败或后端不可用时，不能显示开启成功。

图标采用轮廓、填充或徽标区分状态，并提供可访问的文字说明；不用颜色作为唯一提示。关闭普通窗口不等于退出常驻 App，菜单中的“退出”应撤销本应用保活。

## 首次使用

1. 简短说明用途和运行边界。
2. 普通防闲置休眠可直接使用。
3. 启用合盖功能时，解释需要系统授权的原因，并引导安装／批准 helper。
4. 检查 helper 实际可达与后端设置结果，再显示“已就绪”。
5. 提供停止与恢复入口。

不让用户手写 sudoers、复制终端命令或解除 Gatekeeper 作为正常安装流程。

## 状态与边界

- 保持运行不保证 Wi-Fi、VPN、手机热点或远端 API 永远可达。网络状态单独展示。
- 防休眠不应阻止屏幕锁定。工作电脑的锁屏与企业管理策略继续生效。
- 撤销本应用保活，不保证系统立刻休眠：其他应用可能仍持有断言，或接着外部显示器。
- 不承诺通过热状态识别设备是否在包里。主使用场景为通风桌面。
- 重启后不自动恢复活动租约；先处理遗留改动。

## 后续阶段

任务绑定、按应用触发、可验证的 AI 任务事件接入、Shortcuts、完成通知可后续考虑。第一版不依据低 CPU、无输出或窗口关闭自动推断任务完成。
